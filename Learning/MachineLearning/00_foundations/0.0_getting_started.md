# 0.0 Getting Started: Machine Learning From Hero to Zero

### Introduction

Welcome to the Machine Learning track in this repository. Like the LangChain modules, you will read theory under `Learning/MachineLearning/` and practice in matching notebooks under `Exercises/MachineLearning/`. The full syllabus lives in [roadmap.md](../roadmap.md).

### Learning Objectives

- Understand how this curriculum is organized (Phase 0 + eight algorithm categories).
- Set up Python, Jupyter, and optional ML dependencies for hands-on work.
- Know where datasets and capstone projects live.

### Concept

**Machine learning** is the practice of learning patterns from data so a system can make predictions or decisions without being explicitly programmed for every case. You provide examples (training data); the algorithm adjusts internal parameters to minimize error on those examples, then you evaluate on new data the model has not seen.

This course progresses from **foundations** (Python, EDA, train/test, metrics) through **classical algorithms** (regression, classification, ensembles, clustering, and more) toward **production habits** (pipelines, explainability, APIs, monitoring).

### How to use this repo

1. Open [roadmap.md](../roadmap.md) and follow Phase 0 in order.
2. Read each lesson `.md`, then open the linked `.ipynb` when one exists.
3. Place project data under `Datasets/MachineLearning/`; capstones under `Projects/MachineLearning/`.

### Environment setup

1. **Docker (recommended):** From the repo root, follow the [Deployment Guide](../../../README.md) (`docker compose build` then `docker compose up -d`). The image installs both [requirements.txt](../../../requirements.txt) and [requirements-ml.txt](../../../requirements-ml.txt).
2. **Jupyter:** Open [http://localhost:8888](http://localhost:8888) with your `JUPYTER_TOKEN` from `.env`.
3. **First lab:** Run [0.0 ML sanity check](../../../Exercises/MachineLearning/00_foundations/0.0_ml_sanity_check.ipynb), then continue with [0.3 Python for ML](0.3_python_for_ml.md).

### Real-World Use Cases

2. **Service routing:** Classify citizen complaints to the right department automatically.

You are building the same mental model as a production data scientist: understand the business question, explore data, train and evaluate models honestly, then ship and monitor. Phase 0 gives you the shared vocabulary; later modules specialize by algorithm family.
