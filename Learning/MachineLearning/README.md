# Machine Learning — From Hero to Zero

Complete learning roadmap from **beginner → intermediate → advanced**, aligned with the same structure as the LangChain track in this repository.

| Segment | Purpose |
| -------- | -------- |
| [Learning/MachineLearning/](.) | Theory and mental models (`.md` lessons) |
| [Exercises/MachineLearning/](../../Exercises/MachineLearning/) | Hands-on labs (`.ipynb` notebooks) |
| [Datasets/MachineLearning/](../../Datasets/MachineLearning/) | Raw, processed, and sample data |
| [Projects/MachineLearning/](../../Projects/MachineLearning/) | Category capstones and portfolio work |

**Start here:** [roadmap.md](roadmap.md) — full syllabus, sequence, and milestones.

**Environment:** Use the repo’s Docker + JupyterLab setup ([root README](../../README.md)). For ML notebooks, install extras from [requirements-ml.txt](../../requirements-ml.txt) in your kernel or extend the Docker image when you are ready.

## Learning levels

| Level | Expected capability |
| ----- | ------------------- |
| Beginner | Understand the algorithm, know when to use it, train a basic model, interpret simple results |
| Intermediate | Work with real datasets, tune models, compare algorithms, evaluate performance, avoid common mistakes |
| Advanced | Reproducible pipelines, explain predictions, deploy models, monitor performance |

## Lesson template

Each `.md` file follows: **Learning Objectives → Concept → Mathematical Intuition → How the Algorithm Works → Python Implementation → Evaluation → Common Mistakes → Real-World Use Cases → Exercises → Summary.**

Each `.ipynb` progresses through: **guided coding → independent implementation → evaluation → challenge.**
