# Machine Learning datasets

| Folder | Use |
| ------ | --- |
| `raw/` | Original downloads; do not edit in place |
| `processed/` | Cleaned features ready for modeling |
| `sample/` | Small public or synthetic sets for tutorials |

Prefer sklearn built-in datasets and [OpenML](https://www.openml.org/) in early exercises until capstone projects add municipal-themed data here.
